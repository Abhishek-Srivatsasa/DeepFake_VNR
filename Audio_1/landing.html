🧬 Technology

Built on Best-in-Class AI

A multi-layer architecture combining deep temporal modelling, mesoscopic analysis, and real-time streaming.

🧠

CNN-BiLSTM

Convolutional feature maps feed a Bidirectional LSTM to capture forward and backward temporal dependencies in audio signals.

👁

MesoNet

Mesoscopic-scale analysis of image topology detects Inception-level and face-swap artefacts invisible to the human eye.

🎵

MFCC + Mel Features

13-band MFCC and 128-band mel-spectrograms capture vocal timbre, prosody, and spectral inconsistencies from TTS/VC attacks.

⚡

Flask REST API

Lightweight Python backend streams predictions over a RESTful API, enabling low-latency integration with any frontend.

🔄

Real-Time Pipeline

Frame-level inference at < 1 s latency using optimised TensorFlow Keras inference with batched preprocessing.

📦

Dataset — 7K+ Samples

Trained on 3,500 real + 3,500 fake audio samples for a perfectly balanced, generalisable deepfake corpus.

Development Journey

Phase 1 — Dataset Curation

Assembled 7,000+ balanced real/fake audio samples from diverse speakers, microphones, and TTS engines to eliminate corpus bias.

Phase 2 — Model Architecture

Designed CNN-BiLSTM (audio) and integrated MesoNet (video/image) with custom preprocessing pipelines for each modality.

Phase 3 — Integration & API

Built a Flask REST API connecting TensorFlow Keras models to the React-powered frontend with real-time webcam streaming.

Phase 4 — Optimisation

Fine-tuned thresholds, resolved live-session errors, and achieved sub-second latency on consumer-grade hardware.
